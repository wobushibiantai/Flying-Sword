# 飞剑演示

Godot 4.7.1 / GDScript / Compatibility。打开 `project.godot`，按 **F5**。剑刃主体两侧平行，只有末端收尖；自带 SVG 剑身与着色器，无需外部插件。场景没有标题、标语、靶子编号等文字，操作与参数集中在右侧面板。

## 技能

### 天女散花 · Q

将鼠标移到场内，按住 **Q**，所有飞剑向该点汇聚。保持约 1–2 秒可充分聚拢；松开后均匀向 **360°** 爆射，不受场地边界限制，可飞出整个屏幕。约 1.1 秒后减速转向，逐把飞回聚剑位置，全部回归后恢复原移动模式。

短按也会发射，但聚拢可能尚未完成。面板按钮也支持按住和松开，以当前中心光点聚剑。爆射速度与回归速度分别可调；极高爆速、极低回归速度组合会自然需要更长时间回来，没有用瞬移缩短回归过程。

### 剑河 · E

以场景中心光点为起点，按住 **E** 并移动鼠标瞄准。两条边线显示直线范围，范围延伸出屏幕。松开后，飞剑沿两股相反相位的螺旋曲线前进，交织成 DNA 形剑河，并穿刺沿途靶子。

默认约 65% 的飞剑维持双螺旋主体，约 35% 的飞剑分散到中心及两侧空隙，沿带有轻微游移的纵向路线前进，减少纯双螺旋的命中盲区。填充剑对错开分布在整条剑河中，不集中在尾部。“空隙填充比例”可调 0–0.65，设为 0 恢复纯双螺旋；少量飞剑时比例按完整剑对取整。填充剑与主体使用同样的实际穿刺检测，没有扩大命中半径。

每对飞剑共享前进距离，并在轴线两侧对称分布；不同剑对错开距离，逐次从起点进入剑河。所有飞剑均参与，结束后逐步回归。宽度、填充比例、波长、前进速度和持续时间可分别调节。瞄准阶段也会聚剑，快速松开时用平滑过渡捕获队形。

**Esc** 可提前召回；回归途中可再次释放任一技能。**Space** 会冻结技能运动与计时。切到其他应用会取消正在按住瞄准或聚剑的状态并召回，避免丢失松键事件后卡在蓄力。

技能路径覆盖普通移动方式：爆射、聚剑和双螺旋使用专用运动，普通转弯速度上限测试只约束普通移动与普通回旋。回归使用缓慢转向，转向上限限定在 45–120 °/s，避免极低普通转向参数使技能难以返回。

### 剑河二型 · V

新增独立技能入口：按住 **V** 瞄准，松开释放，也可按住面板“剑河二型”按钮。所有飞剑都沿双螺旋运动，不使用一型的直线空隙填充。

“技能”页的 **二型螺旋带粗细** 控制飞剑在螺旋中心线两侧的真实横向分布，范围 **0–400 px**，默认 **60 px**。设为 0 恢复纯双螺旋细线；加粗后实际剑路和命中覆盖随之变宽，并非仅增加拖尾或光效宽度。带内飞剑使用错开的稳定偏移，保持两条螺旋带的形状。

二型与一型共享剑河宽度、波长、速度、时长、回归参数，但忽略一型的“空隙填充比例”。瞄准范围会计入带厚度：总横向范围为剑河宽度加带厚度。过大的厚度可让两带重叠；低剑数时较粗的剑带会更稀疏，可适当增加剑数。推荐先试 60–120 px。

代码调用：`begin_river(origin, aim, 2)`；`release_river()` 释放。`river_variant` 记录当前类型，`river_band_thickness` 设置厚度。二型同样支持穿刺、暂停、取消和自动回归。`tests/river2_test.gd` 验证零厚度等同纯螺旋、填充比例不影响二型、飞剑实际展开、带宽约束、命中改善与回归。

## 操作

| 操作 | 效果 |
| --- | --- |
| 1 / 2 / 3 | 跟随鼠标 / 自动追击 / 定点环绕 |
| 左键点击、拖动 | 在定点环绕模式移动中心光点 |
| Q 按住、松开 | 聚剑、全向散射 |
| E 按住、松开 | 瞄准、释放剑河 |
| V 按住、松开 | 瞄准、释放剑河二型（纯螺旋剑带） |
| Esc | 结束靶子放置，并召回正在释放的技能 |
| H | 隐藏或显示整个控制面板，保留纯净场景 |
| − / + | 增减飞剑，每次 8 把 |
| T | 开关靶子放置模式，左键放置 |
| 右键靶子 | 移除靶子 |
| R | 恢复三个默认靶子；面板另有清空按钮 |
| F / G | 触发轨迹回旋 / 轴向翻转；相应频率为 0 时关闭 |
| Space | 暂停或继续 |

靶子耐久 16 次命中，击破后 2.5 秒重生，最多 64 个。普通追击与技能均使用线段扫掠检测命中，包含火花反馈。参数面板按“飞剑 / 技能 / 靶场”分页，小窗口内可滚动。

| 普通转弯速度 | 5–1080 °/s | 95 |
| 轴向翻转频率 | 0–10 | 0.65 |

| 轨迹回旋频率 | 0–10 | 0.15 |
| 拖尾时长 | 0.02–4 秒 | 0.48 |

| 剑河宽度 | 30–800 px | 180 |
| 空隙填充比例 | 0–0.65 | 0.35 |
| 二型螺旋带粗细 | 0–400 px | 60 |

翻转、游走、回旋独立，均可设为 0 关闭。翻转是沿剑身长轴的 2D 投影表现，包含面宽变化、正反面交换与高光；不会改变普通飞行轨迹。低转弯速度会产生更大半径，普通模式接近场边时提前转向减速；技能飞行阶段没有边界力。

## 性能

剑身与整群拖尾各由一个 MultiMesh 批量绘制。类型化飞剑状态、预分配浮点缓冲、固定 128 点环形历史，避免每帧创建拖尾字典和大量绘制命令。寻敌分批执行，面板统计每 0.25 秒更新。

拖尾以 30 Hz 记录。超过 160 / 384 / 768 把时，历史点分别每 2 / 4 / 8 个取一次；头部始终连接剑柄，所有飞剑照常模拟和绘制，不削减数量。高数量下历史弧线精度会降低，以控制最大拖尾时长的开销。渲染缓冲根据剑数、拖尾时长和采样密度分配，而非总按最大容量上传。

当前版本本机 RTX 5060 Ti、1280×800、Compatibility 实际渲染测试：关闭垂直同步，固定 60 Hz 模拟步长无上限渲染，预热 90 帧后统计 300 帧墙钟耗时，其余运动参数为默认。

| 场景 | 平均帧耗时 | P95 | 全场绘制调用 |
| --- | --- | --- | --- |
| 1024 把 / 4 秒拖尾 / 环绕 | 11.19 ms | 12.35 ms | 95 |
| 1024 把 / 4 秒拖尾 / 剑河 | 12.04 ms | 13.38 ms | 95 |

这是本机基准，不能视为其他设备或任意参数组合的帧率保证；大量靶子和命中火花会增加开销。原始日志位于上一层 `reference/skills-1024.log` 和 `reference/skills-river-1024.log`。此前版本的优化对比日志保留在 `reference/before-*.log` / `after-*.log`。

## 复用

实例化 `sword_swarm.tscn`。所有位置为该节点局部坐标。

```gdscript
@onready var swarm: SwordSwarm = $SwordSwarm

func _ready() -> void:
	swarm.sword_count = 128
	swarm.focus = Vector2(640, 360)
	swarm.bounds = Rect2(0, 0, 1280, 720)
	swarm.set_mode(SwordSwarm.Mode.ORBIT)

func charge() -> void:
	swarm.begin_charge(swarm.get_local_mouse_position())

func fire() -> void:
	swarm.release_charge()
```

剑河调用 `begin_river(origin, aim)`，瞄准中调用 `aim_river(aim)`，松开时调用 `release_river()`。`recall()` 中断当前技能并回归。`skill` 可用于 UI 状态显示。`speed`、`turn_rate`、`roll_amount`、`wander_amount`、`loop_amount`、`trail_lifetime` 和技能参数均可直接设置。

追击与技能命中目标由 `targets: Array[Dictionary]` 提供；每个字典包含 `p: Vector2`，可选 `respawn: float` 大于 0 表示暂不可攻击。连接 `target_hit(index, position)` 处理伤害。目标移动后更新 `p`；删除目标后可调用 `set_mode()` 清除旧目标选择。演示的靶子耐久、重生与 UI 在 `playground.gd`。
