# 飞剑演示

Godot 4.7.1 / GDScript / Compatibility。打开 `project.godot`，按 **F5**。剑刃主体两侧平行，只有末端收尖；自带 SVG 剑身与着色器，无需外部插件。场景没有标题、标语、靶子编号等文字，操作与参数集中在右侧面板。

## 三浮岛与起降演示

项目默认入口已改为 **world.tscn**，按 **F5** 运行完整浮岛流程。原 **main.tscn** 仍是独立飞剑靶场，可用 F6 单独调试。

- **青岚岛**：青绿地面、树木与练剑场。
- **赤霞岛**：赤褐岩土与秋色树林。
- **寒玉岛**：冰蓝地面与晶簇。

正常地面镜头只覆盖岛内区域，不显示岛边和云海。按 **Tab** 或点击左上角“御剑升空”：角色踏剑升起，镜头连续拉远，地面缩小并显露浮岛轮廓，穿过云层后进入高空俯视选岛视角。一次起飞或降落约 4.2 秒。

高空操作：

| 操作 | 效果 |
| --- | --- |
| WASD / 方向键 | 在云海上自由飞行 |
| 点击浮岛 / 岛名，或 1 / 2 / 3 | 自动飞往指定浮岛 |
| 靠近浮岛后按 Enter / 点击右上角降落 | 穿云下降，镜头拉近，进入该岛 |

起降和高空时地面战斗与按键暂停，落地后恢复；飞剑数量、运动与技能参数保留，各岛靶子布置、耐久、重生计时和角色上次位置在本次运行中分别保存。未访问过的岛初始化三个靶子。原来处于暂停或隐藏面板状态时，降落后保留相同偏好。此版本验证起飞—穿云—高空飞行—选岛—降落的完整体验，地区进度暂不写入磁盘。

实现文件：`scripts/island_world.gd` 管理起降状态、镜头、输入与地区；`scripts/island_terrain.gd` 提供缓存的岛面和侧壁；`scripts/cloud_sea.gd` 绘制岛屿下方云海；`shaders/travel_clouds.gdshader` 提供穿越时的云层。地面仍使用原主角、飞剑与技能逻辑，切岛后鼠标坐标转换到当地坐标系。

验证命令：`Godot --headless --path . --script res://tests/travel_test.gd`。覆盖三个岛往返、连续缩放、穿云、数字键选岛、Enter 降落、状态恢复、当地鼠标坐标、地区保存与参数保持。截图可用 `-- --travel-capture=ground` / `clouds` / `sky` 生成于上一层 `reference`。

## 可控主角

主角使用参考设定图的长黑发、黑灰宽袖外袍、象牙白交领与长内衫、灰蓝腰带和布鞋，保持修长成人比例、有限色板和清晰像素边缘。面部只保留肤色与轮廓，不绘制眼睛、嘴巴；正面、SE / SW 斜侧面和左右侧面的额头与下巴高度对齐，转向时脸长保持一致。左右侧面独立绘制肩臂结构，衣襟、衬里和腰带在两侧呈现不同的遮盖关系；袖口下露出手掌，近侧手臂与躯干有明确分界。

八方向均有待机、行走、抬袖施法与背手飞行序列，每组 8 帧，共 256 帧。起飞、巡航和降落使用独立背手姿态：侧面可见手臂向身后弯曲，背面双手在腰后交叠，双脚固定，只有头发和衣摆飘动。地面和升空角色共用 `player.tscn` 与同一贴图，`flying` 状态优先选用飞行序列并隐藏脚底地面阴影。

资产由本机 **Aseprite Lua API** 实际生成：`art/generate_swordsman.lua` 使用 `Sprite`、`Image:putPixel`、`newCel` 与 `newTag` 绘制、分层和导出。可编辑源文件为 `assets/character/swordsman.aseprite`，含衣袍、袖口、头发三层与 32 个动画标签。运行时读取 `assets/character/swordsman.png`，不依赖 Aseprite 安装。

图集每格 64×80，8 列、32 行；行序为 idle / walk / cast / fly，每组方向 E、SE、S、SW、W、NW、N、NE。待机帧时长 180 ms，其余 100 ms。`scripts/player.gd` 使用脚底锚点和 nearest 采样，原移动、技能与遮挡关系保持兼容。

在项目的上一层目录重新生成：

```powershell
& '<Aseprite.exe>' --batch --script-param out=sword/assets/character --script sword/art/generate_swordsman.lua
```

`art/preview_swordsman.py` 可用 Pillow 输出上一层 `reference/swordsman-animations.png` 与 GIF 动画预览，并检查各组有动画变化、所有帧未被画布裁切。

**WASD 或方向键**八方向移动，斜向速度归一化，松键停止；**Space** 同时暂停角色与飞剑。默认移动速度 240 px/s，在“角色 / 靶场”页可调 30–900。角色足点受场地边界约束。

默认飞剑环绕跟随主角。“环绕跟随主角”开关可关闭，或直接在场内点击切换为原来的定点环绕；鼠标跟随和自动追击模式仍然保留。角色可以边移动边蓄力、瞄准，技能从角色当前位置释放；释放后的剑河保留世界坐标轨迹，结束后飞剑回归主角的最新位置。

复用时可设置 `swarm.return_anchor = player`，使召回追随主角。位置采用共同父节点的局部坐标。`tests/player_test.gd` 覆盖八个朝向、WASD/方向键事件、斜向等速、松键、暂停、边界、环绕跟随、固定中心、移动蓄力及动态回归；`tests/player_gallery.gd` 可渲染八方向图。

## 技能

### 天女散花 · Q

按住 **Q**，所有飞剑围绕角色身体中心形成缓慢旋转的一整圈，剑尖朝外，不再聚在脚下。保持约 1–2 秒可充分成阵；松开后从剑环均匀向 **360°** 爆射，不受场地边界限制，可飞出整个屏幕。约 1.1 秒后减速转向，逐把飞回主角身边，全部回归后恢复原移动模式。

飞剑渲染层高于角色，角色不会遮住飞剑。蓄力环绕半径默认 **112 px**，可在技能页调至 **96–400 px**。围绕的是角色身体中心而非足点，接近队形时先绕到相邻环位，再移入自己的位置，并保留角色避让空间；移动蓄力也保持分离。剑河一型、二型瞄准时使用相同剑环，释放后尚未出发的飞剑继续在环上等待。

短按也会发射，但聚拢可能尚未完成。面板按钮也支持按住和松开，在主角处聚剑。爆射速度与回归速度分别可调；极高爆速、极低回归速度组合会自然需要更长时间回来，没有用瞬移缩短回归过程。

### 剑河 · E

以主角当前位置为起点，按住 **E** 并移动鼠标瞄准。两条边线显示直线范围，范围延伸出屏幕。松开后，飞剑沿两股相反相位的螺旋曲线前进，交织成 DNA 形剑河，并穿刺沿途靶子。

默认约 65% 的飞剑维持双螺旋主体，约 35% 的飞剑分散到中心及两侧空隙，沿带有轻微游移的纵向路线前进，减少纯双螺旋的命中盲区。填充剑对错开分布在整条剑河中，不集中在尾部。“空隙填充比例”可调 0–0.65，设为 0 恢复纯双螺旋；少量飞剑时比例按完整剑对取整。填充剑与主体使用同样的实际穿刺检测，没有扩大命中半径。

每对飞剑共享前进距离，并在轴线两侧对称分布；不同剑对错开距离，逐次从起点进入剑河。所有飞剑均参与，结束后逐步回归。宽度、填充比例、波长、前进速度和持续时间可分别调节。瞄准阶段也会聚剑，快速松开时用平滑过渡捕获队形。

**Esc** 可提前召回；回归途中可再次释放任一技能。**Space** 会冻结技能运动与计时。切到其他应用会取消正在按住瞄准或聚剑的状态并召回，避免丢失松键事件后卡在蓄力。

技能路径覆盖普通移动方式：爆射、聚剑和双螺旋使用专用运动，普通转弯速度上限测试只约束普通移动与普通回旋。回归使用缓慢转向，转向上限限定在 45–120 °/s，避免极低普通转向参数使技能难以返回。

### 剑河二型 · V

新增独立技能入口：按住 **V** 瞄准，松开释放，也可按住面板“剑河二型”按钮。所有飞剑都沿双螺旋运动，不使用一型的直线空隙填充。

“技能”页的 **二型螺旋带粗细** 控制飞剑在螺旋中心线两侧的真实横向分布，范围 **0–400 px**，默认 **60 px**。设为 0 恢复纯双螺旋细线；加粗后实际剑路和命中覆盖随之变宽，并非仅增加拖尾或光效宽度。带内飞剑使用错开的稳定偏移，保持两条螺旋带的形状。

二型与一型共享剑河宽度、波长、速度、时长、回归参数，但忽略一型的“空隙填充比例”。瞄准范围会计入带厚度：总横向范围为剑河宽度加带厚度。过大的厚度可让两带重叠；低剑数时较粗的剑带会更稀疏，可适当增加剑数。推荐先试 60–120 px。

代码调用：`begin_river(origin, aim, 2)`；`release_river()` 释放。`river_variant` 记录当前类型，`river_band_thickness` 设置厚度。二型同样支持穿刺、暂停、取消和自动回归。`tests/river2_test.gd` 验证零厚度等同纯螺旋、填充比例不影响二型、飞剑实际展开、带宽约束、命中改善与回归。

## 性能

剑身与整群拖尾各由一个 MultiMesh 批量绘制。类型化飞剑状态、预分配浮点缓冲、固定 128 点环形历史，避免每帧创建拖尾字典和大量绘制命令。寻敌分批执行，面板统计每 0.25 秒更新。

拖尾以 30 Hz 记录。超过 160 / 384 / 768 把时，历史点分别每 2 / 4 / 8 个取一次；头部始终连接剑柄，所有飞剑照常模拟和绘制，不削减数量。高数量下历史弧线精度会降低，以控制最大拖尾时长的开销。渲染缓冲根据剑数、拖尾时长和采样密度分配，而非总按最大容量上传。

加入主角前的技能版本，本机 RTX 5060 Ti、1280×800、Compatibility 实际渲染测试：关闭垂直同步，固定 60 Hz 模拟步长无上限渲染，预热 90 帧后统计 300 帧墙钟耗时，其余运动参数为默认。

| 场景 | 平均帧耗时 | P95 | 全场绘制调用 |
| --- | --- | --- | --- |
| 1024 把 / 4 秒拖尾 / 环绕 | 11.19 ms | 12.35 ms | 95 |
| 1024 把 / 4 秒拖尾 / 剑河 | 12.04 ms | 13.38 ms | 95 |

这是本机基准，不能视为其他设备或任意参数组合的帧率保证；大量靶子和命中火花会增加开销。原始日志位于上一层 `reference/skills-1024.log` 和 `reference/skills-river-1024.log`。此前版本的优化对比日志保留在 `reference/before-*.log` / `after-*.log`。

## 复用

实例化 `sword_swarm.tscn`。所有位置为该节点局部坐标。

```gdscript
@onready var swarm: SwordSwarm = $SwordSwarm

func _ready() -> void:
	swarm.sword_count = 128
	swarm.focus = Vector2(640, 360)
	swarm.bounds = Rect2(0, 0, 1280, 720)
	swarm.set_mode(SwordSwarm.Mode.ORBIT)

func charge() -> void:
	swarm.begin_charge(swarm.get_local_mouse_position())

func fire() -> void:
	swarm.release_charge()
```

剑河调用 `begin_river(origin, aim)`，瞄准中调用 `aim_river(aim)`，松开时调用 `release_river()`。`recall()` 中断当前技能并回归。`skill` 可用于 UI 状态显示。`speed`、`turn_rate`、`roll_amount`、`wander_amount`、`loop_amount`、`trail_lifetime` 和技能参数均可直接设置。

追击与技能命中目标由 `targets: Array[Dictionary]` 提供；每个字典包含 `p: Vector2`，可选 `respawn: float` 大于 0 表示暂不可攻击。连接 `target_hit(index, position)` 处理伤害。目标移动后更新 `p`；删除目标后可调用 `set_mode()` 清除旧目标选择。演示的靶子耐久、重生与 UI 在 `playground.gd`。
